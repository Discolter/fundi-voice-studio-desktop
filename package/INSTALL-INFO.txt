FUNDI VOICE — ПЕРЕДАЧА И УДАЛЕНИЕ ЗАПИСЕЙ
Studio 1.6.5 + Actor 0.3.4, Cloud 0.4.1

ОБНОВЛЕНИЕ
Заверши программу через Настройки → Завершить приложение или Выход в трее.
Запусти новый установщик поверх старой версии. Удалять прежнюю версию не нужно.
Проекты, актёры, настройки подключения и аккаунты сохраняются отдельно от установки.

ПЕРЕДАЧА
Actor: роль → Сдать на проверку / Сдать исправленное → Выбрать запись и загрузить.
WAV, ZIP, FLAC, MP3, OGG — до 2 ГиБ. Сначала закончи экспорт из редактора.
Дождись «Готово». После проверки полного файла сервером Actor сам поставит уведомление руководителю в очередь.
Studio: Мои файлы в левом меню → Скачать. К списку также ведёт Доступ актёров → Записи актёров.
Запись сохраняется в папку голоса роли или выбранную папку. Совпадающее имя получает номер; существующий файл сохраняется. ZIP не распаковывается автоматически.

ЕСЛИ ОБОРВАЛАСЬ СВЯЗЬ
Общий таймаут передачи увеличен с 75 секунд до 45 минут. Отдельный таймаут простоя — 2 минуты.
Если пропал ответ хранилища, Actor проверяет, полностью ли дошёл файл. Полный файл подтверждается без новой отправки.
Если файл не дошёл целиком, выбери тот же файл повторно. Программа узнает его по содержимому, имени, роли, серверу и аккаунту и повторно использует прежний резерв, даже после перезапуска.
Передача начинается с начала; докачка с середины не поддерживается.
«Мои файлы» → «Проверить загрузку» позволяет проверить старую неподтверждённую запись.

УДАЛЕНИЕ
В Actor в левом меню есть отдельная страница «Мои файлы». Актёр может удалить свои готовые записи и незавершённые загрузки, в том числе от старых версий.
В Studio кнопка «Мои файлы» в левом меню открывает все записи актёров. Владелец может удалить любой готовый или незавершённый файл.
Нажми «Удалить из облака» у нужного файла и подтверди действие. Сначала отмени активную передачу и дождись её остановки.
Удаляются объект в хранилище и строка файла в базе, затем освобождается занятый резерв. При ошибке удаления запись остаётся для повторной попытки.
Счётчик места включает готовые файлы и полные резервы незавершённых загрузок. Общий лимит — 9 ГиБ.
Кнопка Studio «Очистить просроченные» удаляет только просроченные загрузки и незавершённые удаления. Отдельный файл можно удалить сразу.
Удаление не меняет назначение роли и историю уведомлений. Локальные исходники и скачанные копии сохраняются.

СЕРВЕР И ПРОВЕРКА
Cloud 0.4.1 уже развёрнут: база доступна, файловое API включено.
Пройдены проверка передачи 202 МиБ за 88 секунд с совпадением SHA-256, 30 проверок транспорта, 38 проверок процесса загрузки/повторов, проверки интерфейса и изолированные серверные проверки удаления и прав доступа.
Actor собран против официальных библиотек Microsoft .NET Framework 4.8; проверены все внешние обращения к API.
Установщики и системный трей Windows в этой Linux-среде не запускались. Настоящую передачу в ваш R2 проверь после установки.
